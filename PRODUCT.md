# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People using a coding agent to create interactive three-dimensional point sculptures for websites, and visitors trying the resulting browser example.

## Product Purpose

Open-source the particle-effect method used on api.lmm.best as a standalone skill, demonstrate a rotating apple and a flapping bird, and share real browser-recorded GIF evidence.

## Capabilities and Constraints

Static HTTP hosting, native JavaScript modules and Canvas 2D. The runtime is extracted from api.lmm.best under AGPL-3.0-or-later. No runtime framework or network asset fetches. Browser capture and development checks may use Playwright and FFmpeg. Preserve pointer/touch recovery, pause, reduced-motion preferences and native mobile page gestures.

## Brand Commitments

The user requested the existing api.lmm.best homepage effect. Preserve that point field and its interaction. The demo inherits its editorial serif typography and quiet canvas-led composition. Do not replace the point renderer with generated images or unrelated visual effects.

## Evidence on Hand

Source revision and files in NOTICE; working procedural geometry in examples/apple-bird/scenes.js; actual browser checks and recording scripts. The subjects are stylized, not measured models. Phone checks use Chromium emulation.
