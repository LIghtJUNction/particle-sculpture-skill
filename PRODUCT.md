# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People using a coding agent to design interactive 3D particle websites, and visitors comparing the running examples.

## Product Purpose

Make the particle method from api.lmm.best reusable, incorporating HireFerry's semantic scene design and theme roles. Help users choose a coherent style instead of repeatedly generating one fixed homepage.

## Capabilities and Constraints

Use [SKILL.md](SKILL.md) for the workflow and [references/architecture.md](references/architecture.md) for the runtime contract. Static hosting, native JavaScript modules, no runtime packages. Retain AGPL-3.0-or-later and existing attribution. Browser recording uses optional development tools.

## Brand Commitments

The root Apple / Bird demo retains its original identity. New work follows the user's brand and selected direction. Do not infer that every project needs Bodoni, dark green, cards, a full rotation or scatter transitions.

## Evidence on Hand

Source revisions in NOTICE and references/hireferry.md; working procedural models and local checks. Preserve the distinction between real browser checks, static/unit checks and design recipes awaiting implementation.
